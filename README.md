# Pedra, Papel e Tesoura 🎮

Meu primeiro projeto em TypeScript.

## Sobre o projeto

Este é um jogo de Pedra, Papel e Tesoura feito no terminal usando TypeScript.

O jogador enfrenta o computador e vence quem alcançar a quantidade de vitórias definida pela meta.

## Funcionalidades

* Pedra, Papel e Tesoura
* Computador escolhe jogadas aleatórias
* Contador de vitórias
* Contador de empates
* Validação de jogadas inválidas
* Frases aleatórias de vitória e derrota
* Sistema de campeonato

## Tecnologias utilizadas

* TypeScript
* Node.js
* prompt-sync

## Como executar

1. Instale as dependências.
2. Execute o arquivo `app.ts`.
3. Escolha entre pedra, papel ou tesoura.
4. Tente vencer o computador.
